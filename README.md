# Propuestas Vane

Un plugin comunitario de Vane Castiblanco para estudiar clientes, crear propuestas creativas y presentar ideas de forma profesional.

## ¿Qué hace?

- Investiga al cliente desde sus redes, web, archivos o una descripción breve.
- Entrega una auditoría rápida con fortalezas, problemas y oportunidades.
- Crea un prototipo web, una estrategia de redes o una campaña audiovisual.
- Genera imágenes cuando falta un recurso visual.
- Convierte auditorías y propuestas en páginas HTML dinámicas.
- Publica enlaces que el cliente puede abrir sin iniciar sesión.
- Recomienda cuánto cobrar: precio bajo, recomendado y alto en la moneda del cliente.
- Mantiene los precios internos fuera de la propuesta pública, salvo que se solicite lo contrario.

Entre más recursos de la marca compartas —logos, fotografías, videos, redes, página web y referencias— más personalizada podrá ser la propuesta.
